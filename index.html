Projet 01 — Vedette

Pokémon Stadium
Java Edition

Jeu de combat au tour par tour inspiré de Pokémon Stadium, entièrement développé en Java avec un backend MySQL. La base de données recense tous les Pokémon de la Génération 1 ainsi que leurs attaques, reliés via une table de jonction pokemon_attaque. Architecture propre, logique de combat modulaire et données fidèles aux jeux originaux.

Java MySQL POO JDBC Architecture MVC Génération 1
🔒
Projet 02

Snowden &
la Vie Privée

Présentation académique sobre et percutante sur Edward Snowden, construisant le débat entre sécurité nationale et droit à la vie privée. Conçue en PowerPoint dark-themed, générée programmatiquement avec PptxGenJS pour une cohérence visuelle parfaite.

Cyber-Sécurité Éthique du numérique
🌐
Projet 03

Projet Site
& Streaming

Développement d'interfaces web front-end (HTML, CSS, JavaScript) et back-end (PHP/SQL). Création de formulaires dynamiques, gestion de sessions, intégration avec des bases de données MySQL.

PHP HTML / CSS JavaScript MariaDB MySQL

Projet 04

Portfolio
